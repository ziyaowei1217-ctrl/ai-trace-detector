# AI 痕迹检查

检查文件的技术痕迹，判断它是否由程序或 AI 工具生成、加工，或带有从 AI 对话里带出的内容。检查对象是文件，不是文风。

## 第一步：确认场景

从用户的话里判断属于哪一种，判断不出再问一句：

- **审核**（别人交来的文件）：用 `--mode review`
- **自查**（自己的文件要对外发）：用 `--mode self`
- 两者都要或不确定：用 `--mode both`

审核时，问用户是否知道**预期的作者姓名和机构**。知道就传给脚本，这是发现"被 AI 编造的作者信息"的唯一办法。用户不知道就跳过，不要追问。

## 第二步：运行扫描脚本

脚本在本技能目录下的 `scripts/ai_trace_scan.py`，只依赖 Python 标准库。

```bash
python scripts/ai_trace_scan.py <文件或文件夹> --mode review \
    --expect-author "张敏" --expect-org "某某资本" --format json --out report.json
```

- 可以一次传多个文件或整个文件夹。
- 先用 `--format json` 取结构化结果用于分析；需要直接给用户看时用默认的 Markdown。
- PDF 的批注和正文检查需要 `pypdf`。脚本提示缺少时先 `pip install pypdf` 再重跑；装不上就照常出报告，并在报告里写明这部分没查。
- 脚本对文件只读。**不要**修改、另存或"清理"被检查的文件：另存会改写元数据，破坏证据。

不能运行代码的环境：告诉用户无法运行扫描，不要凭印象猜测文件属性。

## 第三步：自己再看一遍脚本看不了的

脚本只做机械匹配。读完它的输出后，补做这几项判断：

1. **名字对不对得上**。比较作者、最后保存者、批注人、路径里的用户名、公司、敏感度标签。它们指向同一个人和机构吗？与提交人对得上吗？一个自称"某券商分析师"写的报告，路径里却是另一个用户名，值得写进报告。
2. **时间线讲不讲得通**。把创建、修改、打印、批注、修订、压缩包时间戳排成一条线。合理的顺序是：创建 → 批注和修订 → 最后保存。检查批注是否集中在几秒内、是否全在整点、是否早于创建或晚于保存。
3. **编辑量与篇幅是否相称**。几千字的文件，修订号 1、编辑 0 分钟、没有 rsid，三者同时出现才有分量；单独一项很常见。
4. **命中的正文片段要回到上下文里看**。一篇讨论 AI 的文章引用"作为 AI 语言模型"不算痕迹。

每项检查的原理、可靠程度和常见误报见 `references/checks.md`。解释某条结果前先查这个文件，不要自己发挥。

## 第四步：写报告

用用户的语言写，结论先行。

**审核报告**包含：

1. 一句话结论，用脚本的四档之一：直接痕迹 / 多项间接疑点 / 少量疑点 / 未发现明显痕迹。
2. 疑点清单，按强、中、弱排序。每条写：是什么、证据原文、在文件哪里、正常情况下有什么解释。
3. 建议向提交人核实的问题，例如"请提供原始编辑文件"或"这份文件是在哪台电脑上保存的"。
4. 没查到的内容。

**自查报告**包含：

1. 对外会暴露的信息清单：名字、路径、公司、批注、修订、隐藏内容、真实打包时间。
2. 收件人用同类工具会看到的疑点。
3. 每项对应的处理办法，只给正当做法：用 Word 的"检查文档"清除个人信息、接受或拒绝修订、删除批注、把从 AI 对话复制的链接换成干净的原始链接、删掉对话残留语句。
4. 如果内容确实由 AI 协助完成，而对方（学校、客户、监管、法院）要求披露，提醒用户按要求披露。

## 必须遵守的界限

- **不给百分比概率**。只用四档结论和强中弱分级。
- **强证据也只说明"文件或其中内容经过了程序或 AI 工具"**，不等于全文由 AI 撰写。一条 `utm_source=chatgpt.com` 只说明这个链接是从 ChatGPT 复制来的。
- **没有痕迹不等于没用 AI**。把 AI 的文字手动粘进正常的 Word 文件，这些检查基本查不出来。报告里要写明。
- **每条疑点都要带正常解释**。另存为、WPS、在线文档导出、公用电脑、文档管理系统都会造成和 AI 生成相似的痕迹。
- **不替用户下处分结论**。涉及学生、员工、对方当事人时，建议先核实再决定。
- **不帮忙伪造或抹除证据来冒充人工撰写**。自查模式的目的是避免无意泄露个人信息和尴尬的残留。用户明确要求伪造作者、编造编辑时间、批注时间，或在要求披露 AI 使用的场合隐瞒，要拒绝，并说明可以帮他做的是正当的清理和如实披露。
- **Claude 等模型的统计型文本水印查不了**。它不是隐藏字符，本工具无法检测；需要时请用户查看厂商是否已提供官方检测工具。
